# ChefAtHome

App Android de receitas para cozinhar em casa.

> Status: fase inicial. O projeto tem a estrutura base em Jetpack Compose e os documentos legais; as funcionalidades ainda não foram implementadas.

## Stack

- Kotlin + Jetpack Compose (Material 3)
- minSdk 24, targetSdk 33
